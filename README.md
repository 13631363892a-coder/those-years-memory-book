## 一、启动与浏览

**最简单：双击 `start.bat`**（Windows）。会自动启动本地服务并打开浏览器。

其他方式：

```bash
# 项目根目录 album/ 下
python serve.py                      # 自动打开 http://127.0.0.1:8000/
# 或
python -m http.server 8000 --bind 127.0.0.1
```

然后浏览器访问 **http://127.0.0.1:8000/**。
端口被占用时可设环境变量 `ALBUM_PORT=8001`。关闭服务按 `Ctrl+C`。

> 需要通过 HTTP 打开，直接双击 `index.html`（file://）会因浏览器本地文件限制导致部分图片不加载。

| 操作 | 方式 |

- **日期原则**：所有显示的日期都来自照片真实 EXIF，无法确定的一律不显示、不编造；没有给照片中的人写任何姓名、身份或故事。

## 四、后续怎么改

### 改文字、改章节（最常用）
只编辑 `assets/js/content.js`：

- `meta`：封面标题、副标题、年份
- `chapters`：章节号、标题、副标题、引言
- `pages`：页面顺序。每一项是一页，`t` 指定版式：

  `cover` `endpaper` `title` `toc` `prologue` `chapter` `full` `spread`（自动占左右两页）
  `story`（文字 + 一大一小对角错落照片）`note`（短句 + 偏右小照片）
  `frame`（拍立得）`duo`（双图）`collage`（拼贴）`timeline`（时间线）
  `quote`（留白短句）`letter`（信）`endpaperBack` `backcover`

  目录页码会自动重算。改完刷新浏览器即可，无需重新构建。

**想整体按时间重新排一遍**（换照片、加照片后推荐）：
```bash
python tools/build_content.py
```
它会读 `selection.json` + `tools_cache/photo-index.json`，自动剔除无 EXIF 相机信息的照片，把剩余照片按拍摄时间排成一条时间线，按章节时间边界与版式节奏重新生成 `content.js`，并打印「时间倒序处」校验结果（应为 0）。想改节奏改脚本里的 `RHYTHM`，想改章节时间边界改 `chapter_for()` 与 `CHAPTERS`。

### 换一张照片
`photos/thumb/<短码>.webp` 与 `photos/full/<短码>.jpg` 都是现成资源。
在 `tools/photo-map.json` 里按原始文件夹 / 日期找到想要的短码，替换 `content.js` 里对应的 `photo:` 或 `id:` 即可。
备选池里还有 79 张有效照片（全部有 EXIF 相机信息与拍摄时间）可直接用。

### 新增照片
1. 把新照片放进 `F:\佳能\初中`（如换目录，改 `tools/scan_fast.py` 顶部的 `SRC`）。
2. 重新扫描与挑片：
   ```bash
   python tools/scan_fast.py                       # 重建 tools_cache/photo-index.json 与 thumbs/
   python tools/detect_people.py
   python tools/make_sheets.py --mode sample --group-by month --per 12 --out new
   python tools/curate.py
   ```
   联系表输出在 `tools_cache/sheets/`，每格下方标注 6 位短码。
3. 把选中的短码加入 `tools/selection.json`（无 EXIF 相机信息的不要加，生成器会忽略）。
4. 生成图片资源，再按时间重新编排：
   ```bash
   python tools/build_assets.py
   python tools/build_content.py
   ```
5. 刷新浏览器。

### 换背景音乐
默认播放内置 Web Audio 合成的柔和和弦（完全本地、无网络请求）。
想用自己音乐：把 mp3 放到 `assets/audio/bgm.mp3`，并在 `content.js` 顶部给 `ALBUM` 加一行
`musicFile: "assets/audio/bgm.mp3"`。开关默认关闭。

## 五、技术实现

- **翻页核心**：沿用原项目 `ui-collections/2d-book/` 的 St.PageFlip 运行时（`assets/vendor/page-flip.browser.js`），保留其 `showCover / usePortrait / useMouseEvents / swipeDistance / showPageCorners / drawShadow` 等初始化参数与左右页书脊阴影 CSS；在其上扩展章节导航、目录跳转、页码、全屏、灯箱、键盘、音乐开关。
- **视觉资产**：移植原项目 3D 精装书运行时的 `cloth.webp` 布纹作封面与桌面质感；书页改用极淡的 SVG 颗粒，避免盖过照片。
- **为什么没用原 skill 的 ImageGen 生成跨页**：原项目的默认工作流要求把照片作为参考交给 ImageGen 生成每一页插画。这与「照片是主角」以及「不把照片上传到第三方 AI 服务」冲突，因此本册保留其翻页运行时与版式语言，但所有页面直接由**本地真实照片 + HTML/CSS 排版**构成，没有使用任何图像生成服务。
- **按时间编排**：`tools/build_content.py` 保证所有照片严格按 EXIF 时间递增（0 处倒序），章节边界也按时间切分；文案里的日期、月份、时间段全部由照片真实 EXIF 推导，不手写、不编造。
- **入场动效**：翻到新页时由 `flip` 事件触发 `.is-active`，页内 `.ph` 按 105ms 间隔依次播放 `photoIn`；跨页与满版大图只淡入；与 StPageFlip 的 3D 翻页互不干扰。
- **性能**：107 张页面图，书页只加载 WebP 缩略图；`data-src` + 当前页 ±4 页范围懒加载，默认只有 2 张图在内存；放大时才按需请求 2000px 大图；`page-canvas` 等比画布让桌面与手机共用同一套版式。
- **本地优先**：无 CDN、无外部字体、无统计、无网络请求；断网可完整浏览。
